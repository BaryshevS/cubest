# examples/ — real-world scenarios with measured token savings

Each folder is a self-contained scenario:

```
NN-scenario/
├── input/          — sample data (log, csv, code, html…)
├── question.md     — what a user (or their AI agent) would ask
├── naive.sh        — what the agent would do WITHOUT cubest
├── cubest.sh       — same goal via cubest
├── measure.sh      — counts tokens for both approaches
└── RESULT.md       — measured numbers (baseline vs cubest, ratio)
```

All benchmarks estimate tokens as **`chars / 4`** — the accepted rule of
thumb for GPT/Claude/Llama-family tokenizers on English/code (see
[OpenAI docs](https://help.openai.com/en/articles/4936856-what-are-tokens-and-how-to-count-them)).
Actual counts on production tokenizers differ by ±10%.
